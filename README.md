## Description 
CodeGuardian directly aligns with the hackathon theme, “Turn idea into impact faster with IBM Bob,” by transforming how developers approach code security. By leveraging IBM Bob’s AI capabilities, CodeGuardian reduces the time between writing code and identifying critical vulnerabilities from hours of manual review to seconds of automated analysis. This enables developers to move from idea to secure, production-ready code significantly faster, while maintaining high security standards without requiring deep cybersecurity expertise.

CodeGuardian is an intelligent code analysis tool designed to help developers and SecOps teams quickly identify security vulnerabilities, assess risk, and improve code quality without the need for time-consuming manual reviews. In an age where new threats emerge rapidly and it’s difficult to find cybersecurity specialists who remain current on every vulnerability, CodeGuardian improves enterprise Security Operations (SecOps) by surfacing prioritised findings and remediation guidance at scale. The CodeGuardian AI acts as an AI-assisted second pair of eyes for enterprise Security Operations. This lets teams scale reviews, reduce time-to-remediation, and focus scarce security talent on the highest-risk problems, a solution that speeds work every day for users and reduces vulnerability detection time from hours to seconds.

Developers often lack fast and accessible tools to detect security issues early in the development process. This is the challenge CodeGuardian was created to solve. Reviewing code line by line is time consuming, tedious and also error prone. Exposed secrets, SQL injection risks or insecure patterns can be easily missed especially under time pressures or rapid prototyping. Critical issues can therefore be overlooked until later in the development cycle which can be costly and difficult to fix thus minimising costly late-stage security fixes. The platform supports many programming languages, making it flexible for all developers.

CodeGuardian can reduce these issues by providing a simple and fast solution in a visually engaging interface where users can upload code files and receive immediate feedback. Using IBM Watson Natural Language Understanding, code files are throughly analysed and any common vulnerability patterns are detected. At the core of CodeGuardian is IBM Bob, acting as an intelligent security co-pilot. Bob interprets code context, identifies risky patterns, and generates human-readable remediation guidance, enabling developers to make faster, informed decisions without needing specialist knowledge.

CodeGuardian then produces actionable AI-driven suggestions for improvement in a modern dashboard. An overall health score is provided, giving developers a quick snapshot of their code's security, as well as a detailed breakdown of vulnerabilities categorised by severity and a clear explanation and suggested fix is provided for each identified issue. This helps developers identify problems and understand how to resolve them. Whilst existing technologies exist that scan code, CodeGuardian is the first to display the information using beginner friendly insights and a clean visual dashboard without needing any set up or expert knowledge to use.

Using charts, metrics and sortable tables, the dashboard provides findings in a functional and intuitive way. A traditionally complex and technical process becomes accessible and actionable, especially for less experienced developers. Futhermore, users can export their analysis results as JSON, making it easy to integrate with other tools or workflows.  CodeGuardian is built upon a lightweight web UI, watsonx semantic code analysis (Granite 8B instruct), and deterministic heuristics that together produce fast, contextual, and actionable results. In addition, the application runs efficiently without any unnecessary outdated IDE plugins or complex configuration. CodeGuardian demonstrates how LLM-driven analysis plus rule-based fallbacks can surface meaningful remediation guidance earlier in the development lifecycle. 

Ultimately, CodeGuardian aims to save developers time and reduces the risk of overlooked issues whilst enhancing developer understanding and decision making, turning ideas into impact faster. As development cycles become faster and more AI-assisted, security risks are introduced earlier and more frequently. CodeGuardian ensures that speed does not come at the cost of security by embedding intelligent analysis directly into the development workflow.

This will no doubt create immense impact to development teams who with CodeGuardian ship faster, and safer, and can help users at any skill level developer high quality software with greater efficiency and confidence. CodeGuardian is designed not only as a standalone tool, but as a scalable solution that can integrate into IDEs and development workflows such as CI/CD pipelines, enabling teams to continuously monitor and improve code security at scale. Our next feature is to implement GitHub url upload.  

## Technologies
We used IBM Bob as an interactive development assistant. IBM Bob was used to design prompt templates, scaffold the Next.js project, generate TypeScript interfaces, draft the watsonx API route, author UI components and tests, and refine scoring heuristics and UX copy.

For analysis we used IBM watsonx.ai (Granite 8B Code Instruct) via a Next.js API proxy. Files are chunked and sent with security-focused instruction prompts that request: vulnerability identification, severity, vulnerable code snippets and line ranges, remediation recommendations, and a confidence score. We gave clear instructions to analyse code as if they were a professional developer with multiple perspectives, particularly from a security, and code quality point of view. Responses are normalized into JSON and aggregated by scoring/score.ts to compute the overall health score and severity breakdown. A rule-based fallback runs when the model is unavailable.
